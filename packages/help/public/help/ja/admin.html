システム管理者ガイド

システム管理者向けのガイドです。ユーザー、ドメインと地域、設定、キャンバスライブラリと参照記録、カメラ、倫理承認、旧アプリのデータ、操作ログについて説明します。

システムでのあなたの作業

作業は Administrator cockpit（管理者コックピット）で行います。これはシステム管理者専用の別のアドレスです。タブは Users、Domains、Regions、Canvases、Cameras、Settings、Ethics approvals、Legacy data、Action log です。アドレスには、開いているタブの名前が常に入ります（例：…/admin#/settings）。

  • 設定とキャンバスを変更できるのは、あなただけです。
  • 臨床的に管理される値（採点、タイマー、キャンバスの有効化）を変更するときは、研究責任者のメールアドレスとPINも必要です。研究責任者の承認がオン（初期設定）の間は、保存時にあなたの画面で入力してもらいます。
  • すべての変更は、変更前と変更後の値とともに操作ログに記録されます。ログの内容は編集も削除もできません。
  • 新しいセッションは、その時点で有効な設定のスナップショットを保存します。変更はその後に作成されたセッションにだけ適用され、既存のセッションには適用されません。

サインイン

管理者コックピットのアドレス（コックピットのアドレスの後に /admin を付けたもの。例：https://<server>:5174/admin）を開いて、サインインします。システム管理者は検査者用のアドレスではサインインできません。また、ほかのユーザーはここではサインインできません。どちらの場合も、正しいアドレスが案内されます。

パスワードを5回間違えると、アカウントは15分間ロックされます。各タブのHelp（ヘルプ）ボタンを押すと、このガイドの該当する部分が開きます。

ユーザー

一覧には、有効なユーザーの名前、メールアドレス、役割、ドメイン、地域、状態が表示されます。Search（名前またはメールアドレス）、Role、Status（有効、無効、すべて）で絞り込めます。

役割

役割使うもの
システム管理者管理者コックピット
研究者検査者コックピットと分析ポータル。研究責任者PINがあれば、研究責任者になります
検査者検査者コックピット：参加者とセッション
分析者分析ポータル：個人を特定できない研究データのみ

ユーザーを作成する

  1. + New user を押します。名前、メールアドレス、役割、画面の言語、ドメイン、地域を入力します。
  2. 16文字のパスワードが自動で作成されます。Generate を押すと別のパスワードが作成されます。Create を押す前にコピーして、本人に直接渡してください。メール送信の機能はありません。
  3. 研究者の場合は、任意で Research Director PIN（6桁）を設定できます。設定すると、その人は研究責任者になります（一覧に緑のバッジが付きます）。

編集、ロック解除、リセット、無効化

  • Edit では、名前、役割、言語、ドメイン、地域、状態を変更できます。メールアドレスは変更できません（代わりに新しいユーザーを作成してください）。パスワードは空欄のままにすると変わりません。Generate で新しいものを作成することもできます。リセットするとアカウントのロックも解除されます。
  • ロックされたアカウント（琥珀色のLocked（ロック中））は、Unlock で再び使えるようになります。
  • PIN：空欄のままにすると変わりません。削除するには Remove the Research Director PIN にチェックを入れます。役割を研究者以外に変更すると、PINは削除されます。
  • Deactivate（一覧で確認の後に実行）を使うと、そのユーザーはサインインできなくなります。Reactivate で元に戻せます。ユーザーが削除されることはありません。
  • 役割の変更や無効化は、サインイン中のユーザーにも15分以内に反映されます。
  • 自分自身を無効化したり、自分の役割を変更したりすることはできません。

ドメイン

ドメインは、ILT検査のために児童・生徒をまとめるグループです。たとえば、研究グループ、プログラム、対象集団などです。必ずしも地理的な区分ではありません。参加者は全員、いずれか1つのドメインに属します。採点の設定と言語の構成は、ドメインごとに独自の値を持てます。

  • + New Domain：コード（英字、数字、アンダースコア。大文字で保存され、後から変更できません）、ヘブライ語と英語の名前、説明を入力します。
  • Edit では、名前と説明を変更できます。
  • Deactivate を使うと、そのドメインは新しい参加者やユーザーの選択肢に表示されなくなります。既存の参加者やユーザーはそのドメインのままです。有効なドメインが少なくとも1つ必要です。

地域

地域は地理的な区域です。たとえば教育地区などです。参加者への設定は任意です。ILTの進行に関する設定（タイマー、ウォームアップ、動画、テンプレート）は、地域ごとに独自の値を持てます。地域の作成、名前の変更、無効化は、ドメインと同じ方法で行います。すべての地域を無効にしてもかまいません。

設定

まずレベルを選びます：System、Domain、または Region です。

  • System（システム）では、すべてのグループが表示されます：採点、ILTの進行、言語、そしてガバナンス・プライバシー・デバイス・ログです。
  • ドメインでは採点と言語が、地域ではILTの進行に関する設定が表示されます。独自の値を持たない行には「システムに従う」（または「初期値に従う」）と表示されます。Set own value で独自の値を設定し、Follow System で独自の値を削除します。
  • 設定の説明にポインターを合わせると、初期値と設定できる範囲が表示されます。

変更と保存

  1. 値を変更します。変更した行は強調表示され、Undo と Back to default が表示されます。画面下部のバーに変更の数が表示されます。
  2. Review and save を押すと、すべての変更が変更前と変更後で一覧表示されます。必要に応じて理由を入力してください。
  3. 変更にNeeds a Research Director PIN（研究責任者PINが必要）な場合は、研究責任者がメールアドレスとPINを入力します。1回の承認で、すべての変更が承認されます。
  4. Save を押します。範囲外の値は受け付けられず、赤で表示されます。総合スコアの3つの重みは、合計で100%にする必要があります。

History には、選んだレベルでの変更が新しい順に表示されます。日時、設定、変更前と変更後、変更した人、承認した人、理由がわかります。

知っておきたい設定

  • Pass/fail threshold on the composite score（総合スコアの合格・不合格の基準値）と、3つの総合スコアの重み（初期値は速度50%、正確さ25%、ペンの持ち上げ25%）。基準値を設定するまで、合格・不合格は「未設定」と表示されます。
  • Timers（タイマー）：合図までの無操作時間（20秒）、最後の枠の後の無操作時間（30秒）、琥珀色の警告までの追加時間（10秒）、ブロック前の切り替えカウントダウン。
  • Warm-up block（ウォームアップブロック）のオン・オフ（地域ごと）。
  • Languages（言語）：有効な言語と初期設定の言語。言語ごとに、ILT・ノート・文字のキャンバス、記入の方向、ブロックを左右反転するかどうかを設定します。キャンバスに記録された記入順序が記入の方向と異なる場合は、注意が表示されます。
  • Allow research sessions (after ethics approval)（研究セッションを許可する（倫理承認の後））（倫理承認を参照）、Hand video recording (subject to consent)（手元動画の録画（同意が条件））（地域ごと）、Clinical changes need the research director PIN（臨床的な変更には研究責任者PINが必要）（オフにするには必ず研究責任者が必要です）、そして介入に関する設定（介入セッションでの練習シート、練習から保持確認までの日数、3行目の類似性ヒントを表示する）。

キャンバスライブラリ

キャンバスは、子どもが書き込むページです。ILTのブロック、ノートのページ、介入用の文字シートがあります。キャンバスは言語 → キャンバスセット → キャンバスの順にまとめられています。Language と Type で絞り込めます。

  • + New canvas set：言語、種類（ILTブロック、ノートのページ、介入用の文字）、名前を入力します。セットは名前の変更と無効化ができます。
  • + Load a canvas：セット、コード（例：ILT_3X5_HE）、名前、JSON形式の形状データ（直接入力するか Read from a file で読み込みます）、そして任意で採点プロファイルを指定します。キャンバスはDraft（下書き）として読み込まれます。
  • 各キャンバスには状態があります：Draft（下書き）（編集可能）→ Active（有効）（使用中。変更されません）→ Retired（廃止）。
  • 設定ではキャンバスをコードで指定します。新しいセッションには、そのコードの有効なバージョンが使われます。

使用中のキャンバス（例：ILT_3X5_HE、ILT_3X5_EN、NOTEBOOK_HE、NOTEBOOK_EN）を、計画なしに廃止したり置き換えたりしないでください。すべてのセッションで使われています。

キャンバス：プレビュー、プロファイル、バージョン

  • Preview（プレビュー）：家と点が表示されます。Box numbers and fill order を使うと、枠のIDと書く順序が表示されます。サイズは、実寸（96 dpiの画面で正確）、実寸の2倍、ウィンドウに合わせる、から選べます。タブレットでの実寸は、参照モードで確認します。
  • Scoring profile（採点プロファイル）（ILTと文字のキャンバス）：点の順序（例：A → B → C）、点ごとの判定半径（mm）、正確さの重み（%）、必須かどうか。重みは合計で100%になります。さらに、ブロックごとに想定されるペンの持ち上げ回数、枠の記入順序、標準速度（mm/s）、許容幅（± %）も含まれます。
  • Draft（下書き）は、編集（形状、プロファイル、名前）、確認（Check で修正が必要な点が一覧表示されます）、削除（参照記録がある場合を除く）ができます。変更は Save draft で保存します。
  • Activate（有効化）：問題がないことが必要です。研究責任者の承認がオンの場合は、研究責任者のメールアドレスとPINも必要です。有効化すると、そのコードを使う新しいセッションにはこのバージョンが使われます。
  • New version（新しいバージョン）では、有効なキャンバスの編集可能な下書きのコピーを作成します。それを有効化すると、前のバージョンは廃止されます。1つのキャンバスにつき、下書きは1つまでです。
  • Domain overrides（ドメインの上書き）：ドメインは、有効なキャンバスに対して独自の採点値を持てます（研究責任者PINで承認します）。変更した値は強調表示されます。Follow the canvas profile で上書きを削除します。上書きは新しいバージョンにも引き継がれます。
  • Retire（廃止）は、設定がまだそのキャンバスを指定している間は受け付けられません。
  • 「N個のセッションステップで使用」と「設定で指定」で、キャンバスが使われている場所がわかります。

タブレットでの参照記録

プロファイルの値の一部は、参照モードのタブレットで描いたサンプルから得られます：

  1. キャンバスで Pair a tablet in reference mode を押します。タブレットに6桁のコードを入力します。タブレットには琥珀色のバー「参照記録（子どものセッションではありません）」が表示されます。ほかのキャンバスを開いている間も、タブレットはペアリングされたままです。
  2. Show on the tablet at true size：定規でサイズを確認し（ILTの家は 35 × 25 mm です）、Done をタップします。何も記録されません。
  3. Record a sample block：子どもが書くべき順序で、すべての家を埋めてから Done を押します。コックピットに記入順序とペンの持ち上げ回数が表示されます。Accept でそれらをプロファイルに保存し、Clear でサンプルを破棄します（監査用に保管されます）。不完全なサンプルは、破棄することしかできません。
  4. Record the normal speed：書くことに慣れた人が、自然な速さで1行（または選んだ行）を書き、Done を押します。速度は子どもの場合と同じ式で計算されます。Accept で標準速度として保存します。
  5. 終わったら Disconnect the tablet を押します。タブレットはコード画面に戻ります。
  • Record for：下書きの場合、記録はキャンバス自身のプロファイルに入ります。有効なキャンバスの場合はドメインを選びます。値はそのドメイン独自の値になり、Accept には研究責任者PINが必要です。
  • 標準速度が記録されるまで、セッションでは速度スコアと総合スコアが「未設定」と表示されます。キャンバスに標準速度が設定された後に作成されたセッションでは、これらのスコアが表示されます。
  • Recordings of this canvas には、すべての記録が一覧表示されます：日時、内容、対象、値、状態、記録した人、判断した人。

カメラ

机のカメラは、子どもの書いている手を録画します。サーバーは、同じネットワーク上の ONVIF カメラを自動で見つけます。アドレスを入力する必要はありません。

  1. 各カメラの専用アプリで、カメラのアカウント（ユーザー名とパスワード）を設定します。すべてのカメラで同じものにします。
  2. Cameras で、Site camera account にそのアカウントを入力し、Save を押します。カメラが確認され、それぞれReady（準備完了）になります。パスワードは暗号化して保存され、二度と表示されません。
  3. Search the network で新しいカメラを探します。
  • 各カメラには、状態（準備完了、アカウントなし、アカウントが違う、応答なし）、パン・チルトができるかどうか、最後に検出された日時、Picture（現在の画像）が表示されます。
  • Rename でカメラに名前を付けます（Enter で保存、Escape で取り消し）。例：「カメラ2」。
  • Own account で、1台のカメラに独自のアカウントを設定します。Use the site account でサイトのアカウントに戻します。
  • Retire で、カメラをペアリングに使わないようにします。Restore で元に戻せます。
  • 録画には、Hand video recording (subject to consent)（手元動画の録画（同意が条件））の設定と、参加者の同意も必要です。検査者は、タブレットに表示されるQRコードでカメラをセッションにペアリングします。
  • 画面上部に警告が表示される場合は、カメラの中継サービスが応答していません。中継サービスが動くまで、カメラの確認、ペアリング、録画はできません。

倫理承認

セッションの実施の根拠となる承認です。種類（例：介入プログラム、研究）、承認機関、承認番号、有効期間を記録します。

  • + Add an approval で承認を1件登録します。「有効開始日」は「有効終了日」より後にできません。
  • Withdraw を使うと、承認は取り下げ済みとして一覧に残ります。Restore で元に戻せます。
  • 各承認には、それを使ったセッションの数が表示されます。

Research sessions（研究セッション）は、次の条件をすべて満たす場合にのみ作成できます：Allow research sessions (after ethics approval)（研究セッションを許可する（倫理承認の後））の設定がオンであること、研究の承認が今日の時点で有効であること、参加者の同意が研究での利用を認めていること。このタブの上部に、研究セッションがオンになっているかどうかが表示されます。

旧アプリのデータ

以前のアプリケーションの .xls ファイルから結果を取り込みます（1ファイルにつき1つの指標：手の持ち上げ → ペンの持ち上げ、区間の幅 → 幅、合計時間、書字時間、空中時間）。

  1. Files：ファイルを選びます。各ファイルの指標は、ファイル名またはシート名から自動で判別されます。手動で指定することもできます。1つの指標を2つのファイルから取り込むことはできません。
  2. 新しい子どもに使う Domain と、Session label（例：「Legacy」）を選びます。
  3. Check files：新しい子どもとすでにシステムにいる子どもの人数、ブロックの行、サンプルが表示されます。この時点では、まだ何も書き込まれません。
  4. Import を押します。各子どもは旧番号で照合されるか、LEG-<number> として新しく作成されます。同じラベルで再度取り込むと値が更新されます。重複することはありません。

ファイルには、学年、性別、SES、学校、生まれ月が含まれていません。これらは、検査者が記録を完成させるまで「未記録」のままです。利き手は L/R の値から取得します（1が右、0が左）。旧データの区間の幅の単位は確認されていないため、そのままの値で保存します。Imports には、すべての取り込みが一覧表示されます。

操作ログ

システム内のすべての操作が、新しい順に表示されます。初期設定では直近7日間が表示されます。

  • Filters（絞り込み）：From / To（Last 24 hours と Any time もあります）、Event types（分野ごと、または分野全体）、Severity、User、Session code、Domain / 地域、Free text（メッセージ、詳細、イベント名）。Search を押します。
  • 行をクリックすると、詳細（ユーザーのメールアドレス、記録、デバイス、アドレス、詳細情報）が表示されます。Show more で次の100件を読み込みます。
  • Export to CSV で、絞り込んだ項目（最大50,000件）を保存します。時刻は UTC です。エクスポートしたこと自体もログに記録されます。
  • 重要度Security（セキュリティ）は、サインインの失敗、研究責任者PINの誤り、ユーザーの変更を示します。パスワードやPINがログに表示されることはありません。

問題が起きたとき

表示される内容対処方法
「研究責任者のメールアドレスまたはPINが正しくありません」研究責任者にもう一度入力してもらいます。必要であれば、Users で新しいPINを設定します。
キャンバスを有効化できない操作ボタンの下に表示される問題（例：点の重みの合計が100にならない）を修正し、下書きを保存してから Check を押します。
キャンバスを廃止できない設定がまだそのキャンバスを指定しています。先に設定で別のキャンバスを選んでください。
スコアが「未設定」と表示されるキャンバスの標準速度を記録し（参照モード）、合格の基準値を設定します。
カメラが「アカウントが違う」または「応答なし」になるカメラのアプリと Cameras タブでアカウントを確認し、カメラが同じネットワークにあることを確認します。
ユーザーがロックされているEdit → Unlock を使うか、新しいパスワードを設定します。
