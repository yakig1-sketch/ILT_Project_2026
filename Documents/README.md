## Notes

- **From FRS v3.5 / Architecture v5.6 / DDD v1.6 on, the specifications are Markdown files maintained in this repository**, which is the source of truth. The earlier Gemini-authored Word/PDF editions (up to FRS v3.4, Architecture v5.5, DDD v1.5, in English and Hebrew) are in each folder's `Previous_Versions/`.
- Where a specification and the Clinical Decisions Register disagree, the register wins.
- Files with a `_2026-08` suffix came from the Drive subfolder `ILT Project 2026-08` and differ from the same-named file at the Drive root.
- Videos (`*.mp4`, `*.mov`) and macro presentations (`*.pptm`) are stored with Git LFS.
